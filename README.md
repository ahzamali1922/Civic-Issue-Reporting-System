# Civic Issue Reporting System V2 — starter context files

This bundle contains:
- `backend/requirements.txt` — starter dependencies for the Django REST backend.
- `ml/requirements.txt` — starter dependencies for the ML training/inference environment.
- `AGENTS.md` — project context and working rules for AI coding assistants and contributors.

## Important
These dependency lists are starting points, not a verified lockfile. Compare them with the repository's current imports, Python version, package manager, and deployment target before replacing existing dependency files. Keep existing working versions unless you have a reason to upgrade. For reproducible installs, test the environment and then pin the resolved versions.

Suggested Python version: 3.11 for the separate backend and ML environments. TensorFlow compatibility can vary by OS and hardware; check the official compatibility matrix for your machine before installing.
